# 01 · 填充算法原理

本文完整阐述本插件的填充算法：数学基础、数据流、关键设计决策。
这是整个仓库最核心的一篇，读完即可理解 `dissolve_*` 全部代码。

---

## 1. 算法总览

填充效果的本质：**一个"波前"从若干种子点出发，随时间扫过图层的像素区域，
扫过的位置被逐层填充上颜色/渐变/源图内容，未扫过的位置保持透明或源图。**

整体数据流：

```
种子点(splat)
   │  软边圆绘制 (max 累积)
   ▼
种子场 ── BFS 8邻域 ──► 距离场 dist(x,y)   （= 逐帧 3x3 膨胀的帧号场，数学等价）
   │                        │
   │                        ├──► 归一化距离场 nd ∈ [0,1]（形状外=2.0）
   │                        │
   │                        └──► 波前半径 r(t) = 时间进度
   │
   ▼
baseFill = (dist ≤ r(t)) ? 1 : 0   （波前软边 1px）
   │
   ▼
fillMap（覆盖率场）＝ baseFill，可被三路调制：
   ├─ 速度图 speedMap（overlay+lerp）
   ├─ 边框 edgeMap（borderControl）
   └─ gamma / exposure
   │
   ▼
多层着色：每个预设层 = 时间窗口 [start,end] × 填充强度 × 颜色/渐变/源图
   │  按 order 升序 src-over 合成
   ▼
最终合成：效果层与源图按 compOverOriginal 混合 → 输出
```

## 2. 种子与距离场

### 2.1 种子点（splat）

每个预设层可以带一个种子点（16.16 定点坐标，默认 45% × 45%）。
种子以**软边圆**的形式写入种子场：

```
d² = (x−cx+0.5)² + (y−cy+0.5)²
d² ≤ r²        → factor = 1.0（圆内实心）
(r−1)² < d² ≤ r² → factor = (r²−d²) / (r²−(r−1)²)（1px 软边）
buf = max(buf, factor)
```

- 多个种子点取 max 累积（可叠加）。
- 种子有**硬阈值 gating**：层延迟阈值 `delay/100 ≤ 进度` 时该种子才激活——
  延迟参数让各层的波前错峰启动。

### 2.2 距离场（BFS 切比雪夫）

从种子场做 **8 邻域 BFS**，得到每个像素到最近种子的距离：

```
dist(种子像素)=0；每向外扩张 1 格距离 +1（切比雪夫度量）
```

为什么用 BFS 而不是逐帧膨胀：逐帧 3×3 max 膨胀每帧推进 1px，
N 帧后的覆盖范围恰好等于"距离 ≤ N"的像素集——与一次性 BFS 完全等价，
且 BFS 只需算一次（形状不变时），性能高一个量级。

### 2.3 归一化距离场 nd

```
nd = (dist − minD) / (maxD − minD)
```

- `minD/maxD` 只统计**图层不透明像素**的距离范围（透明外扩区不参与），
  保证波前在整个播放时长内连续扫过内容（首帧到达最近内容、末帧到达最远内容）。
- 形状外（无距离）标记为 `nd = 2.0`，永不填充。

## 3. 波前与填充强度

### 3.1 时间 → 进度

```
seconds  = current_time / time_scale          （AE 帧时间）
p01      = clamp((已过帧数 + 起始偏置×总帧数) / 总帧数, 0, 1)
```

- **起始偏置 12%**：t=0 时波前即有 12% 半径——打开工程立即能看到效果
  （否则首帧波前半径≈0，效果完全不可见，这是排查"没效果"时最容易踩的坑）。
- **循环**：合成时长超过预设周期时，时间按周期取模折叠（fmod），
  波前周期性扫过，任何时刻播放都有动画。
- **循环淡出包络**：周期末尾 85%→100% 平滑淡出填充强度（源图文字层豁免），
  消除"满填充突然消失"的硬跳变观感。

### 3.2 波前半径 → 填充场

```
framePx = minD + (maxD − minD) × (frame / totalFrames)
baseFill = (dist ≤ framePx) ? 1 : (dist ≤ framePx+1 ? 软边 : 0)
```

即：波前半径随帧号线性推进，扫过处填充强度=1，波前边缘 1px 软边平滑。

## 4. 填充链（Fill_GPU）

填充强度场再经过一条可选的 9 步链调制（与 GPU 管线的 Fill_GPU 一致）：

| 步 | 操作 | 公式 |
|---|---|---|
| 2/3 | 高斯模糊 H/V | 权重 `exp(−0.5·(x/R)²/0.06)`，浮点半径 R/R+1 双核按小数插值，边界 clamp-to-edge |
| 4 | gamma/exposure | `v>0.0001 ? clamp(pow(v,γ)·exp, 0, 1) : 0` |
| 5 | speedOverlay | `o = dst<0.5 ? 2·dst·src : 1−2(1−dst)(1−src)`；`out = lerp(o, dst, 影响度)` |
| 9 | borderControl | `out = dst·(1 − 边框影响×(1−edgeMap))`，clamp [0,1] |

速度图可由源图通道生成（亮度/单通道），经四边形扭曲采样实现空间变化的速度场——
速度图让波前在空间上"快慢不一"（如边界附近变慢、纹理区域变快）。

## 5. 多层着色系统

预设 = 最多 5 层，每层定义：

```
order             合成顺序（小者先画=底层）
start / end       时间窗口 [0-99%]（层只在窗口内显现，波前扫过时逐层点亮）
mode              1=实色 2=渐变 3=源图
color / stops     实色 RGBA / 渐变颜色停靠点（最多 12 个）
gradientMode      1=沿波前位置取色（径向） 2=按窗口内时间取色
grow              波前偏移带（g≠0 时填充带 = 1−smoothstep(p01, p01+softEdge, nd−g×0.01)）
overlayMode       混合模式（1 正常 / 3 正片叠底 / 4 颜色加深 / 6 相加 / 7 滤色 / 9 叠加 / 10 柔光 / 12 颜色 / 14-17 模版剪影族）
overlayOpacity    层不透明度
blur / displace   层内模糊 / 噪声位移扭曲
```

### 5.1 层窗口（win）

```
lo = min(start,end)×0.01；hi = max(start,end)×0.01
win = smoothstep(lo−0.03, lo+0.03, p01) × (1 − smoothstep(hi, hi+0.03, p01))
```

窗口上下沿各 3% 平滑过渡。层权重：

```
wA = win × fillG × colorAlpha × opacity × 循环包络
```

### 5.2 层填充强度 fillG

- `g == 0`：fillG = fillMap（覆盖率场）——层随波前整体点亮
- `g ≠ 0`：fillG = 波前偏移带——填充集中在一个距种子 g×1% 的环带上，
  形成"条纹推进"效果（如 2 Color Stripes 的色带）

### 5.3 渐变取色

- gradientMode 1：`pos = nd`（波前位置，径向渐变随波前扩散）
- gradientMode 2：`pos = (p01−lo)/(hi−lo)`（窗口内时间位置，渐变随时间演变）

### 5.4 mode=3 源图层

直接取源图像素（`col = srcRGBA`，alpha 参与合成）。它把源图"盖"在已有层之上——
文字保持自身颜色、彩色填充留在透明背景（Reveal 语义）。面板"文字模式"参数
可切换为跳过源图层，让彩色直接覆盖文字区域。

## 6. 合成

### 6.1 层间合成

按 `order` 升序逐层 src-over 叠加（含混合模式运算），输出层的 RGBA。

### 6.2 与源图合成

```
叠于原图（compOver）:  out = src×(1−a) + layer×a；outA = max(srcA, a)
替换源图（out）     :  out = layer×a + src×(1−a)；outA = srcA×(1−a)
```

## 7. 关键设计决策（踩坑记录）

1. **生长 = 形状内流动（原版 Borders 语义）**：波前传播在传播掩码内进行
   （BFS/JFA 受 alpha 约束，"填充不能穿越透明区域，半透明限制流动，完全透明
   视为阻断"），显示同样裁剪到掩码——掩码外填充置 0。未裁剪时填充覆盖整个
   矩形区域——观感为"方块在文字上生长"而非"文字的生长"（用户实证）。
   种子须位于不透明区域才生效；掩码可经边界强度/扩展/桥接膨胀（见 §8.2）。
2. **种子锚定到内容包围盒而非渲染世界**：矢量文字层在合成分辨率下渲染时，
   world=合成尺寸、图层≈内容包围盒；按 world 定位种子会导致"拖动图层、
   波前相对文字漂移"的诡异现象。按内容包围盒定位后与图层位置无关。
3. **距离场缓存**：距离场只依赖（形状, 激活层集合, 传播掩码），与时间无关——
   按指纹缓存后每帧只需 O(n) 阈值化，播放性能大幅提升。
4. **t=0 可见性**：起始偏置保证打开工程即有可见波前（见 §3.1）。
5. **循环包络**：避免周期回绕的硬跳变（见 §3.1）。

## 8. 生长来源与传播边界（2026-08-18 重构）

### 8.1 统一种子模型

三种"生长来源"（面板参数）都归结为同一模型：**种子场 → 掩码内 BFS → 填充场**，
差异只在种子场怎么构建：

| 来源 | 种子 = | 特点 |
|---|---|---|
| 点（默认） | splat 软边圆（层延迟 gating） | 单点/多点波前扩散 |
| 噪波 | 0x30B80 斜坡输出 > 0.01 的像素 | 噪波白区作起始点；斜坡含进度项 `+2.5p−1`，种子随生长逐步出现（"一边生长一边出现"） |
| 图层 | 源图 luma > 0.05 的像素 | 外部图层亮区作起始点，波前从源图内容处扩散 |

种子必须在传播掩码内（掩码外种子被 BFS 阻断）。噪波/图层生长的种子随时间
（或源图）变化 → 距离场不缓存，逐帧重算（区域级成本可接受）。

### 8.2 传播掩码（原版 Borders & Bridges）

传播受掩码约束：填充不能穿越透明区域——BFS 只在掩码内流动（流体感）。
掩码 = 形状 alpha 膨胀 spread 像素：

```
spread = 边框扩展 + 桥接厚度/2 + (1 − 边框强度)×40
```

- 边框强度 = 1（默认，强边界）：无溢出项，传播 = 形状本身；强度降低 →
  填充可越过形状边缘溢出（低值越界语义，溢出区域可见）。
- 桥接模式非"无"：额外膨胀桥接厚度/2，波前可越过分离元素的空隙
  （多元素字间空隙被桥接，波前连续流动）。
- 边框扩展：直接增加膨胀量。

显示裁剪使用同一掩码（溢出/桥接区域可见填充）。掩码只依赖（形状, 参数）→
缓存复用；距离场缓存键包含 spread，参数变化自动失效。

### 8.3 Speed 步进（离散模拟步）

Speed = 每秒模拟步数。模拟步是离散整数：帧号取整（floor）后再映射波前半径——
speed < 帧率时波前每隔数帧才推进 1 步（跳帧）；speed ≥ 帧率时每帧恰好 1 步。
实测（speed=25%、30fps）：填充像素数每 4 帧跳变一次（步进而非平滑滑动）。

### 8.4 GPU 路径门控

GPU 路径（JFA）只支持点生长 + 默认传播掩码（spread=0）；
噪波/图层生长与桥接/弱边界走 CPU 直通管线（语义一致，性能由两级缓存保障）。
