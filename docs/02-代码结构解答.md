# 02 · 代码结构解答

本文回答"代码是怎么组织的、每个文件/函数干什么、参数怎么对应"。

---

## 1. 工程模块划分

```
FillingEffect.cpp       插件外壳（AE 交互层）
├── dissolve_core.*     算法核心（纯 C++，无 AE 依赖）
├── dissolve_styles.*   预设多层渲染系统
├── dissolve_direct.*   直通渲染管线（默认 CPU 路径）
├── gl_renderer.*        GPU 渲染器（OpenGL 3.3）
└── preset_data.*        预设数据
```

依赖关系（自上而下）：

```
FillingEffect.cpp
   ├─► dissolve_direct (renderPresetDirect 主流程)
   │      ├─► dissolve_styles (blendPixel 混合)
   │      └─► preset_data
   ├─► dissolve_core (噪声/边缘/静态场)
   ├─► gl_renderer (GPU 路径, 默认自动)
   └─► preset_names_cn
```

## 2. 插件外壳 FillingEffect.cpp

### 2.1 入口与命令分派

- `PluginDataEntryFunction2`：注册效果（名称"测试"、matchName `ADBE TestFill2`）
- `EffectMain`：SEH 保护的命令分派（ABOUT / GLOBAL_SETUP / PARAMS_SETUP / RENDER /
  SMART_PRE_RENDER / SMART_RENDER / USER_CHANGED_PARAM）
- 所有渲染统一走 **传统 Render 路径**（不启用 SmartRender），
  全局标志 `out_flags2 = 0`。

### 2.2 渲染入口

```
PF_Cmd_RENDER → Render() → readParams() → renderWorldSafe() → renderWorld()
```

- `readParams`：读取 35 个面板参数到 `dissolve::Params` + `BrushUI` + `PresetOverride`
  （含"自愈"：越界点位置在渲染内修正为默认 45%，不写回工程）
- `renderWorld`：完整渲染一帧

### 2.3 renderWorld 一帧的流程

1. **世界准备**：`w/h` = 输出世界尺寸；`copyToFloat` 把源世界拷入浮点缓冲
   （处理 src/output 尺寸差与原点偏移，只读 extent 有效区）
2. **时间映射**：`seconds = current_time / time_scale`；循环折叠；
   `p01` 与起始偏置；`prog` 输出（见原理篇 §3.1）
3. **渲染区域**：以内容包围盒（extent）为区域，区域外不渲染——
   矢量文字层在 4000×4000 合成分辨率下只渲染内容矩形，性能提升几个量级
4. **静态场**：噪声场 + Sobel 边缘场，按形状指纹缓存（多线程互斥锁保护）
5. **直通管线**：`dissolve::renderPresetDirect` 生成图层 RGBA
6. **最终合成**：效果层与源图按 compOverOriginal 混合
7. **写回**：`copyFromFloat` 输出到 AE 世界

### 2.5 全局标志（GLOBAL_SETUP）

```
out_flags  = PIX_INDEPENDENT | DEEP_COLOR_AWARE | NON_PARAM_VARY
out_flags2 = 0
```

`NON_PARAM_VARY` 是**时间变化声明**：输出依赖帧时间 → AE 必须逐帧重渲，
不能跨时间复用帧缓存。这是"播放没有动画"类问题的关键标志
（缺失时 AE 认为参数不变输出不变，只渲染一帧并复用）。

## 4. 直通渲染管线 dissolve_direct

这是**默认渲染路径**，全部内核在此：

| 函数 | 职责 | 对应原理篇 |
|---|---|---|
| `splatFillMap` | 软边圆种子（max 累积）| §2.1 |
| `bfsChebyshev` | 8 邻域 BFS 距离场 | §2.2 |
| `dilateMaxField` | 3×3 max 膨胀（对照实现）| §2.2 |
| `rampKernel30B80` | 渐变层填充值斜坡 | §5 |
| `overlayLerp30E50` | overlay+lerp 合成 | §4 |
| `quadWarpSpeedMap` | 四边形扭曲速度图采样 | §4 |
| `gaussBlurField24F50` | 高斯模糊（全抽头）| §4 |
| `renderPresetDirect` | **渲染主流程** | 全文 |

### renderPresetDirect 主流程

1. 层参数整理（点/阈值）
2. fillMap 生成：
   - 点生长：splat+BFS → baseFill（帧号阈值化）
   - 噪波生长：`rampKernel(噪声, S, p01)` 调制
   - 图层生长：源图灰度 × baseFill
3. Fill 链（模糊 → gamma/exposure → speedOverlay → borderControl）
4. 层循环：按 order 升序，每层计算
   `win × fillG × 取色 × opacity × loopEnv`，`blendPixel` 合成
5. 输出图层 RGBA

### 性能设计

- **BFS 距离场缓存**：键 = 形状指纹 ^ 点/半径配置指纹，再 ×31 + 激活层掩码；
  掩码是离散事件（延迟阈值），缓存命中后每帧仅 O(n) 阈值化
- **静态场缓存**：噪声/边缘只依赖形状，按形状指纹哈希缓存
- **区域渲染**：只在内容包围盒上计算

## 5. 预设数据 preset_data.h

- `PresetLayer`：一层（order/start/end/mode/color/stops/grow/overlay 等）
- `Preset`：duration/repeat/compOverOriginal/nLayers/layers[5]
- `kPresets[30]`：30 个预设（2 Color Stripes / 3 Colors Gradient / Fire / Wave 族…）

## 6. GPU 渲染 gl_renderer / gl_shaders

OpenGL 3.3 隐藏窗口渲染器，GLSL 实现与 CPU 路径数学一致。默认自动：GPU 优先（区域渲染实测 25-52ms/帧），失败自动回退 CPU。
AE 内 GL 上下文与 AE 自身 GPU 管线冲突（实测 7s/帧），当前默认走 CPU。

## 7. 测试

`source/tests/`：9 个回归套件（核心/样式/合成/GPU/生长回归/直通管线/批量自检/
调试渲染/循环包络），`build_tests.bat` + `run_all.bat` 一键构建运行。
